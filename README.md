# ExhibitsScrappers

## WHX Dubai DEC Exhibitor Scraper

Complete Selenium-based scraper for World Health Expo Dubai 2027 exhibitors at **Dubai Exhibition Centre (DEC)**.

```bash
cd whx_exhibitor_scraper
pip install -r requirements.txt
python main.py
```

See [whx_exhibitor_scraper/README.md](whx_exhibitor_scraper/README.md) for architecture, DOM notes, CLI flags, and resume behavior.
